# 🖱️ Windows 7 Clicker Remastered

Un juego casual inspirado en el clásico estilo *clicker*, donde el objetivo es **hacer clic en el logo de Windows 7** y comprar mejoras desde el menú del juego.  
Construido con **Pygame** para **Python 3.15**.

## 🎮 Cómo jugar
1. Haz clic en el **logo de Windows 7** para ganar puntos.  
2. Usa los puntos para comprar **upgrades** en el menú del juego.  
3. ¡Sigue clickeando y mejora tu experiencia retro!
